# 描画・素材・運用の詳細

[READMEに戻る](../README.md)

このページは観戦用の描画と素材の補足です。AIの走行判断とAPIの使い分けは [README](../README.md) を参照してください。

## 描画と通信の分離

サーバーから約500ms間隔で届く位置を `RaceTimeline` に保存し、Three.jsの `requestAnimationFrame` が約1秒遅れの同じ時間軸をサンプリングします。受信のたびに補間を最初から開始せず、バッファ内の確定位置をつなぎます。長い通信断では最後の確定位置で止まり、再接続時にはバッファを作り直します。観戦用の遅延であり、AIの2D操作画面は最新のサーバー状態を使います。

Reactはネットワーク更新と操作UIを担当し、毎フレームの車両座標をstateで配りません。以前の25ms間引きは60Hz画面で実質30fpsになっていたため撤去しました。観客席・建物・木はインスタンス描画、影は1024角に軽量化し、描画負荷が継続して高い場合だけ解像度を下げます。フレームレートは端末のGPUと画面の更新周期に依存します。

| 手法 | 今回の判断 |
| --- | --- |
| 確定状態のバッファ補間 + 独立した描画ループ | 採用。通信の揺れとReact更新の影響を分離 |
| WebSocket / SSEで高頻度配信 | 将来の低遅延化の選択肢。今回の描画間引きは配信方式を変えても直らないため現行APIを維持 |
| クライアント独自の物理予測 | 不採用。相手との衝突・分岐結果がサーバーと食い違うのを避ける |

重なりを作る補間経路は確定位置へ切り替えます。同一分岐の別ルート内に留まる区間はこの制限を除外します。3D要素の `data-render-fps`、`data-frame-p50-ms`、`data-frame-p95-ms`、`data-draw-calls`、`data-pixel-ratio` は2秒窓のローカル計測値です（外部送信なし）。フレーム間隔は描画コールバックの周期で、GPUの処理完了時間とは異なります。

## 観戦カメラと音楽

観戦画面は、赤・青のRoadster GLBモデルを使う3Dサーキットです。車の位置・レーン・速度・進路はサーバーのレース状態から描画します。3D側に独立した勝敗判定や操作処理はなく、Computer Useのエージェントは2D操作画面を使います。

自動カメラは車に近い透視投影の追従・横からのショット・接戦の2台表示を中心に切り替えます。全体表示は40秒周期のうち3秒だけで、残り37秒は車の近くから映します。手動カメラも選べます。画面の動きを減らすOS設定では自動カメラを固定します。3D表示に対応しない環境では2Dに切り替えます。

AIの準備中は55秒を目安にタイムゲージと各ドライバーの接続・READY状況を表示します。55秒を超えた場合は「もう少し時間がかかっています」と表示します。実際のスタートは両AIのREADY後の5秒カウントダウンで決まります。

走行中は `public/audio/turbo-battle-final-lap.mp3` をループ再生し、終了・中止で停止します。ブラウザーの自動再生制限がある場合は観戦画面のBGMボタンを押してください。音量調整とミュートができます。実況の発話中はBGMを下げます。

## 3D素材と独立した試作

Roadsterの10色のGLBと色一覧は `public/models/tesla-roadster/` にあります。コースでは赤・青を表示し、WebGLを使えない環境ではSVGの車を表示します。8方向・上面スプライトとシートは `public/models/tesla-roadster/sprites/` にあります。

元の10台サーキット試作は `public/roadster-circuit/` に、実行に必要な車体と13種類の小物とともに保存しています。開発サーバー上の `/roadster-circuit/race.html` で確認できます。コースは `race.html` のThree.jsコードが生成しており、コース単体のGLBはありません。この試作はAgent Grand Prixのレース処理とは独立しています。

障害物を含む小物13種類の3Dモデル、斜め視点・見下ろし視点の透過PNG、2DアトラスとZIPは `public/roadster-circuit/props/` にあります。各ファイルの対応は同フォルダの `manifest.json` を参照してください。これらは配信用の素材で、小物モデルやスプライトを実際の障害物表示・ドライバー画面へ適用する作業とは区別しています。

素材一覧は開発サーバー上の `/preview/assets`、Roadsterのデモ走行は `/preview/roadster` です。いずれもAI対戦の実行証跡ではありません。
